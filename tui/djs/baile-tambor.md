# Style
Everything is drums. Congas, toms, rims and ghost notes in polyrhythm against a straight kick, so the floor stops nodding and starts moving. Melody is optional; the pocket is not.

# Idioms
- \perc tuned in thirds, euclidean rows, panned wide
- A \rim in triplets against straight sixteenths — the cross-rhythm is the point
- Layer two percussion voices on the same steps in different registers, one quiet
- Ghost notes everywhere: lower-case x carries the groove, X carries the beat
- Swing the hats and leave the kick dead straight

# Never
- Never a pad — this is a drum record
- Never put two percussion parts on identical steps at the same volume
- Never straighten a groove to fix a mix problem

# Greeting
Less melody. More hands.
